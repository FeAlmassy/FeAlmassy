### Featured models

**[AlgoritmoGenetico](https://github.com/FeAlmassy/AlgoritmoGenetico)** · [![PyPI](https://img.shields.io/pypi/v/algoritmo-genetico?style=flat&color=3776AB&label=PyPI)](https://pypi.org/project/algoritmo-genetico/)
A machine learning library built from scratch: a linear classifier (binary and ordinal) trained by a genetic algorithm instead of gradient descent. Selection, crossover, mutation and fitness are all implemented by hand in NumPy.
```bash
pip install algoritmo-genetico
```

**[Palete-Caixa](https://github.com/FeAlmassy/palete_caixa)** · *operations research*
Pallet loading problem solved with integer linear programming (PuLP/CBC): fits as many boxes as possible on a pallet without overlap, and generates distinct layouts through cuts that forbid repeated solutions. Comes with an interactive Streamlit app.

**[Portfolio Optimizer](https://github.com/FeAlmassy/Portfolio_Optimizer)** · *quantitative finance*
Fully vectorized mean–variance optimization in NumPy: the whole weight simplex is evaluated in a few matrix operations, producing the efficient frontier, max-Sharpe and min-variance portfolios, and a historical backtest.

**[Modelo de Abate](https://github.com/FeAlmassy/Modelo_Abates)** · *mathematical modeling*
Finds the most profitable time to slaughter cattle: fits weight and feed curves by least squares, then maximizes profit given market prices. Served as a FastAPI app with Plotly charts.
